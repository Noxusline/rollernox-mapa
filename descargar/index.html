RollerNox para Android

Versión de prueba (fuera de Google Play). Solo para Android.

Descargar RollerNox
  1. Tocá Descargar RollerNox y esperá que termine (unos 50 MB).
  2. Si el navegador ofrece Abrir, no lo toques.
  3. Abrí Mis archivos (o Archivos) → Descargas → tocá rollernox.apk.
  4. Si te pide permiso: Configuración → activalo → volvé → Instalar.
  5. Si aparece Play Protect: Más detalles → Instalar de todas formas.
  6. Entrá con tu cuenta de Google y elegí tu nombre de usuario.

Si ya la tenés, instalá la nueva encima: no se pierde nada.
